### Features

- **Private & Persistent Desktops**: Isolated virtual Linux machines with persistent disk volumes for code, browser state, and workspaces.
- **MCP Gateway**: Built-in Model Context Protocol server enabling LLMs (Hermes, Claude Desktop, custom agents) to control virtual desktops, browsers, files, and terminals.
- **Modern Management Dashboard**: Sleek web interface with live desktop viewing (noVNC), real-time host resource metrics, instant search, and dark/light modes.
- **Fine-Grained Scopes**: Generate granular MCP tokens bound to individual computers or entire fleets with full audit trails.
- **Wake-on-Call**: Automated sleep and wake lifecycle management to optimize host CPU and memory consumption.
